The method, reverse-engineered

Your reference images are built from exactly three layers. The soft "pillowy" forms and the grain are independent passes — the grain is applied over the finished gradient, not baked into it.

  1. Ground. A near-black canvas. Not pure black — around #060608.
  2. Form — stacked layers, not one blur. Each shape is its own layer with a soft-but-defined silhouette (edge transition ≈ 0.5–1.5% of the canvas width — look at where a dark fold meets a bright one: the boundary is far crisper than the shading inside either region). Critically, the silhouette is not a clean alpha ramp: noise perturbs the layer's alpha in the edge zone, so each shape dissolves into whatever sits below it — the border is made of speckle, not a smooth fade. The interior is shaded by its gradient fill with hard contrast — a near-white tint toward the light collapsing into a near-black shade of the same hue — plus a bright rim light hugging the lit edge. That contrast is what makes the overlaps read dramatic instead of flat.
  3. Grain. One Gaussian noise pass over the flattened composite — the grain runs unbroken across every silhouette edge, which is how you can tell it comes last.

What the pixels say

I separated the grain from the base gradient (heavy blur = base, residual = grain) and measured it in both reference images:

PropertyMeasuredMeaning
amplitudeσ ≈ 13–18 / 255≈ 6% noise — strong, poster-grade grain
R·G·B correlation0.78 – 0.95mostly luminance grain + ~35% color speckle
autocorrelation @1px0.62 – 0.74grain cells ≈ 2 px, not 1-px white noise
σ in deep shadows≈ 5.5grain fades to ~⅓ near black — blacks stay clean
excess kurtosis+0.7 – +2.9heavier tails than pure Gaussian (clipping)

The 2-px cell size means the noise was generated at roughly half resolution and upscaled (or grain-blurred ~0.7 px). That single detail is most of the "film" feel — 1-px noise reads as digital static instead.

Recipe in Photoshop

  1. One blob per layer. Shade each with a high-contrast gradient fill (near-white tint → near-black shade of the same color) and add a light Inner Glow on the lit edge for the rim.
  2. Give each layer a layer mask: Gaussian Blur the mask ≈ 8–20 px on a 1500-px canvas, then Add Noise ≈ 20–40% directly on the mask. Noise in the mask is what turns the silhouette into a speckled dissolve instead of a clean fade. Do not merge and blur everything together.
  3. Flatten, then: new layer filled 50% gray, blend mode Overlay.
  4. Add Noise ≈ 12%, Gaussian, monochromatic off for the slight color speckle.
  5. Gaussian Blur 0.7 px on the noise layer — this creates the 2-px cells.
  6. Double-click the layer → Blend If, drag the "Underlying Layer" black slider right (split it with ⌥) so grain fades out of the shadows.

Recipe on the web (SVG filter)

For live use — hero backgrounds, cards — overlay feTurbulence on any CSS gradient:

<!-- place over your gradient, mix-blend-mode: overlay; opacity ≈ .5 -->
<svg><filter id="grain">
  <feTurbulence type="fractalNoise" baseFrequency="0.55" numOctaves="2"/>
</filter></svg>
/* baseFrequency 0.55 ≈ the 2-px grain cell at 1× DPI */

Recipe in code (what this page runs)

// per pixel, after rendering the blurred gradient base:
n     = mono + 0.35 * perChannel          // ~0.85 channel correlation
atten = clamp(luminance / 60, 0.25, 1)    // protect the shadows
out   = base + n * σ15 * atten             // clip to 0–255
// mono & perChannel: Gaussian fields generated at ½ res, bilinear-upscaled

Shaping the forms by hand

Each silhouette is a closed quadratic Bézier spline. The eight handles you drag are the control points — they sit off the curve and pull it toward them; the curve itself passes through the midpoint between each neighbouring pair. That is what keeps every outline continuous and tangent-smooth no matter where you drag: there are no corners to break.

// segment i, between control points P[i] and P[i+1]
start = midpoint(P[i-1], P[i])
end   = midpoint(P[i],   P[i+1])
ctrl  = lerp( midpoint(start, end), P[i], tension )
// tension 1.00 = full Bézier bulge · 0.00 = straight polygon edges

Geometry is stored normalised — centres as a fraction of the canvas, control points as a fraction of its short side — so a shape you tune at preview size exports pixel-for-pixel identical at 3× and survives an aspect change without stretching. Spread stays live on top of that: it moves the generated centre, and your drag is an offset added to it, so the slider keeps working after you have positioned things by hand. Shuffle redraws every shape from a new seed and discards manual edits; reset shape restores just the selected one.

The linear gradient fill switch swaps each layer's radial shading for a linear ramp along the light axis. Radial reads as an inflated, pillowy volume; linear reads flatter and more graphic — closer to a folded paper plane than a balloon, and noticeably cleaner when shapes are stretched wide.

Every slider in the rail maps onto one of these measured numbers, and the defaults are the measurements — so the starting output matches the reference fingerprint. Swap the palette swatches for your brand colors, push the shapes where you want them, and export.
